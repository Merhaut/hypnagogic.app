Privacy Policy

This Privacy Policy explains how the Hypnagogic Android application handles user data.

Privacy at a glance

Hypnagogic is designed to work locally on your device. The app does not require an account and does not send your session data to the developer or to a Hypnagogic server.

No account. No ads. No analytics. No tracking.
No cloud service. No AI service.

Data collection and sharing

Hypnagogic does not collect, transmit, sell, or share personal or sensitive user data with the developer or with third parties.

The app does not include advertising, analytics, tracking, telemetry, crash-reporting, cloud, or AI service SDKs. It does not require registration or an online account.

Data stored on your device

To provide its features, Hypnagogic stores information locally on your device. Depending on how you use the app, this may include:

  • application and session settings,
  • session history and technical session logs,
  • timestamps and cue/response timing,
  • session outcome and related technical events,
  • notes that you choose to add to a session.

The session-log database is stored in the app's private Android storage and is explicitly excluded from Android cloud backup and device-to-device transfer.

Android may back up some ordinary application preferences according to your device and account backup settings. The developer does not have access to those Android backups.

JSON export and folder access

If you choose to enable JSON archiving or export session data, Android's system file picker lets you select where the files are saved. Hypnagogic receives access only to the location that you explicitly select.

Exported JSON files can contain the session information described above, including any session note you entered. Hypnagogic does not upload exported files to the developer.

After a file is exported, it is under your control. If you choose a location provided by a third-party or cloud-storage application, that provider may process the file according to its own privacy policy.

Device access and permissions

Hypnagogic uses Android capabilities needed for its core function, including vibration, a foreground service, wake lock, and notifications. These are used to run and signal an active session reliably.

The app does not request access to your location, contacts, camera, microphone, phone calls, SMS messages, or broad device storage. The app itself does not request Internet access.

Data security

Session data is kept in Android's private application storage, protected by the operating system's application sandbox. Hypnagogic does not operate a server that receives or stores your session data.

Files that you deliberately export are stored in the destination you choose and are protected according to the security of that destination and your device.

Data retention and deletion

Local session data remains on your device until you delete it in the app, clear the app's storage, or uninstall the app. Because the developer does not receive or store this data on a server, there is no server-side copy to retain or delete.

Exported JSON files are separate copies and remain in the location you selected until you delete them yourself.

Website

The hypnagogic.app website is a static site hosted using GitHub Pages. The site does not intentionally use advertising or analytics scripts. GitHub may process basic technical information about web requests as the hosting provider under its own privacy terms.

Changes to this policy

This Privacy Policy may be updated when the application's features or data-handling practices change. The current version will always be published on this page.

If you have any privacy-related questions, contact hello@hypnagogic.app.
